# MonitoredSpinChains

Spin-off (pun intended) of the MonitoredFeedbackCircuits code. Started fresh to have an easier time to implement spin-1 dynamics with less functionality. 

Implements a Quantum Circuit with projective measurements and feedback operations. The supported models are 

| spin-1/2 | spin-1 |
|:--------:|:------:|
|    SU(2)     |   Biquadratic    |
|    Fredkin     |   Motzkin    |
